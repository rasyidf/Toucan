Toucan v0.24.0 — Editor comfort and resource compatibility

v0.24.0 preview release notes, download guidance, compatibility changes and outstanding acceptance checks. The GitHub release is a draft.

activeUpdated 2026-10-25Edit on GitHub ↗

Toucan v0.24.0 makes translation sessions easier to navigate and expands resource compatibility and BabelEdit migration. This is preview software; keep translation files in version control.

Release status: draft, prepared on 2026-10-25. Downloads attached to the draft become public when it is published. Until then, v0.23.0 remains the public download. Packaging checks do not replace the remaining native acceptance checks.

#Highlights

  • Translate with context. Source-first language cards use two columns in wide editors and stack in narrow windows. Focused fields show character and word counts, placeholder warnings and translation-memory provenance.
  • Review by keyboard. Approve and Next (Ctrl/Cmd+Enter), Next Pending Translation and Accept Suggestion retain target focus across pages. Commands support shortcut reassignment.
  • Undo a whole batch. Copy, namespace move, Replace All, accepted pre-translation and approval batches undo as one step, including review metadata. Cancelled or conflicting previews leave the workspace unchanged.
  • Start with less setup. First-run setup offers language, theme and optional AI credentials. A dismissible editing guide can be reopened from Help. The welcome screen hides project-only navigation until a project opens.
  • Find notification history. The status-bar flyout retains host and plugin notifications, timestamps and actions. Reading history clears the unread badge even when project or validation totals refresh.
  • Import BabelEdit projects. A folder containing one .babel project imports settings, concepts, comments, approvals and JSON file mappings. Saving writes toucan.tproj and leaves the original project unchanged.
  • Keep resource details intact. Exact-resource options, generated-source protection, framework extraction diagnostics and local spelling imports accompany expanded compatibility fixtures.

#Fixes you will notice

Source edits, linked placeholder renames and undo/redo immediately refresh target warnings, including plural variants. Unrelated row refreshes preserve the caret. Dialogs share themed title bars and opaque Windows surfaces; narrow layouts keep their actions visible. Plugin toolbar commands now follow command availability. macOS source/license materials live in Contents/Resources, fixing a signing failure caused by treating their dotted directory as nested code.

Format fixes cover intentional empty translations, Java properties encoding and filenames, Rails YAML locale wrappers and sequences, BabelEdit metadata conversion, and Excel comments and per-language approvals. See the full changelog and format support matrix before round-tripping existing files.

#Downloads and installation

Open the GitHub release after publication. The draft is visible only to repository collaborators.

Toucan-0.24.0-portable-x64.zipWindows x64: extract the complete archive into a writable folder and run Toucan.exe. No separate .NET installation is required. Keep the third-party folder beside the executable.

All four native packages are attached to the release draft. Local unsigned MSIX output is for packaging inspection and is not an installable release asset without a trusted signing certificate.

For macOS builds, the current packaging script uses an ad-hoc signature unless a Developer ID is configured. If Gatekeeper blocks the app, use System Settings → Privacy & Security → Open Anyway after attempting to open it. Notarization remains open.

#Compatibility and known limits

The app version is 0.24.0. Toucan.Plugins.Abstractions is 1.2.0, matching the additive plugin API 1.2 resource contracts; existing folder plugins remain supported. Projects and settings can change before v1.0. Back up existing projects before migration.

Native Windows accessibility, packaged installation/upgrade acceptance and external connector revalidation remain open. Historical macOS/Linux readiness assumptions are recorded separately from executed checks. Saved validation-rule enable/severity preferences are not yet enforced at validation entry points (APP-06). Dictionary and Source Control panels are planned; glossary, persisted review revisions and remote synchronization are future milestones.

The spelling engine's matching source and license notices accompany the app; no dictionary data is bundled. See known issues, acceptance evidence and packaging instructions.

#Packaging evidence

The native package run passed for Windows x64, Linux x64, macOS ARM64 and macOS Intel. Packages were built from 3fc9777 and attached with matching SHA-256 sums and source provenance. Each platform verified the spelling-engine source/notices; both macOS app bundles passed strict ad-hoc signature verification. This verifies packaging, not the remaining native workflow or installation acceptance gates.
