## Status of remaining items

1. **Command-toolbar gap:** Resolved in `f92d5ce`: commands with toolbar placement render in the editor toolbar, update on registration changes, and follow workspace availability.
2. **Version declaration:** Resolved in `f92d5ce`: `Directory.Build.props` declares `0.24.0`, satisfying `minHostVersion: 0.23.0` for extensions requiring the platform release.
3. **Connection lifecycle integration:** Core supports connection scopes (`OpenConnectionAsync`), but no production desktop/CLI connection-management caller exists yet. Tracked as an inherited integration gap in [known issues (APP-05)](../known-bugs.md#app-05).
4. **External connector desktop verification:** The separate `toucan-plugins` repository is absent from this checkout's parent directory, so package-only desktop/CLI acceptance of the external REST connector remains open ([APP-05](../known-bugs.md#app-05)).
5. **Native and cross-platform release acceptance:** Automated Windows tests and packaging probes pass; native Windows accessibility, macOS/Linux workflows, and compatibility M7c remain release gates ([QA-03](../known-bugs.md#qa-03)).

Verify external connector desktop/CLI flows when the sibling repository is available, and execute native/platform acceptance gates on respective operating systems.
