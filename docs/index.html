three modes

Translate, review, and audit in the same window.

The layout follows VS Code: a key tree on the left, the translation pane in the middle, an inspector on the right. Switch modes without opening another tool.

Editor

Every language for a key on one screen, with suggestions from translation memory as you type.

  • Tree or flat list sidebar
  • Paginated or infinite scroll
  • Inspector with stats, suggestions, and key details
  • Zen mode hides everything but the card

Review

Filters to unapproved items. Approve or reject each one while validation warnings sit next to the text.

  • Only what still needs a decision
  • Approve or reject one item at a time
  • Warnings shown inline, per language

Audit

A read-only view of each key's approval state and change history.

  • No accidental edits
  • Approval state per language
  • Who changed what, and when

placeholders

Placeholders stay intact

Toucan recognises {{var}}, {0}, %s and :param in the source and flags any translation that uses different ones.

Hi {{name}}, %s left
Hai {{name}}, sisa %s
ai integration

AI, off until you turn it on

One switch for the whole app, asked once on first run. Connect a service, then translate with it, analyze translations for wrong terms and tone, or check source strings. Every prompt Toucan sends is a plain file you can edit for all projects or commit with one project in .toucan/prompts. Keys stay in an encrypted store in your profile, never in the project.

plugins · preview

Extend it with a .dll

Plugins are .NET assemblies that add file formats, translation providers, validation rules, and framework profiles. New in v0.18.0, they run in the macOS and Linux app and the CLI. The Windows app does not load plugins.

  • Nothing loads until you enable and trust it.
  • Trust is pinned to a SHA-256 hash of the plugin's files, so a changed plugin asks again.
  • Contracts ship as the Toucan.Plugins.Abstractions package.

platforms

Your files stay on your machine.

No account, no upload, no server. Text leaves your machine only when you run a translation provider or turn AI on. API keys live in one secret store in your user profile, encrypted at rest: DPAPI on Windows, AES-GCM with a per-user key on macOS and Linux.

Preview software. Toucan is at v0.20.0 on Windows, macOS and Linux, and every build is a preview until 1.0. Settings and project files can change between releases, so keep your locales in version control and report what breaks.
